# Studio

The five-agent creative room is retired. This chat is the director until you say build. Then the same chat builds. It does not call the old specialists.

## What you type

| When | Say this |
|---|---|
| An example or a feeling | Paste the link, then say what you want from it |
| The direction is right | `Build` |
| One piece is wrong | Name the piece |
| Not this | `Leave it` |

## Who does it

| Hat | When |
|---|---|
| Director | While you are still deciding |
| Maker | After you say build |

Unreal, Microsoft Designer, and image or 3D generators are how a shot gets made. They are not a second website.
