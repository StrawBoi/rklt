# Idea cards

Empty until a creative pass is requested. One file per section: `docs/rklt/ideas/<section>.md`.

A card is a proposal. It does not change the site, the routes, or the copy. The skill `rklt-creative-room` writes cards here. Promoting a card into `docs/rklt/specs/` or into code needs a dated entry in `docs/rklt/decisions.md`.
